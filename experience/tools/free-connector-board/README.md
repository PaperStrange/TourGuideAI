# Kyoto source-board packaging

Package the verified source evidence for static hosting with Node 24. The package
contains all 35 manifest records, the evidence manifest, research producer,
README and snapshot board. The authored canonical `index.html` adds the two actual
geometry tests with their unchanged plots and exact result reports: 44 content
files plus `package-manifest.json`. Photographs, metadata and rights remain
unchanged. This entry presents research evidence; the application runtime is separate.

```sh
node experience/tools/free-connector-board/package.mjs artifacts/realism-01/free-connector-next/public-package COMMIT_SHA
node experience/tools/free-connector-board/check.mjs artifacts/realism-01/free-connector-next/public-package
```

The packager requires a new output directory inside the ignored source workspace
and the inspected base commit. Actual source producer hashes remain separate from
that commit identity.
It verifies the evidence hashes and records each actual packaged file's SHA-256.
The browser driver uses Playwright 1.62.1 and installed Chromium. Browser profiles
and temporary files remain inside the ignored QA directory. It checks the real
canonical page and source board at 1,280 px and 375 px widths, six/four decoded
images, horizontal overflow, photo attributions, qualification wording, actual
two-method results, all ten/seven local HTML links, all 44 served content files
and canonical-entry identity. Reports retain the executed
driver and package identity. Errors fail the run and preserve the report.

After publication, the same driver accepts the actual HTTPS folder entry and a
new ignored output directory as its arguments. Normal TLS verification remains
enabled. The source-board checks establish static layout and evidence delivery;
they supply no complete-route or physical-device fluency acceptance.

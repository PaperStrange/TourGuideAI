Nearby (Click anywhere on Map)

Click on map triggers a Nearby API call using the clicked coordinates. This API returns metadata about nearby street view imagery sequences—such as capture timestamps, direction, and sequence IDs. The application then highlights these sequences on the map or displays additional information, enabling users to explore the collected imagery in context.

This interaction model provides an intuitive way for users to discover and inspect street view data coverage across geographic regions.

An imagery sequence represents a series of geotagged street view images captured in a continuous motion, often by a vehicle, bicycle, or person carrying a camera. Each sequence includes metadata such as GPS coordinates, timestamps, camera heading, and possibly elevation data for every image frame.

Retrieve list of Sequence's photo:

GEThttps://api.openstreetcam.org/2.0/photo/?lat={latitude}&lng={longitude}&zoomLevel={zoomLevel}&join={joinType}&orderBy={orderField}&orderDirection={orderDirection}

Click Photo (Click photo list below portal)

Requesting all related photos by [sequenceID] showing a complete collection trace (sequence).

A photo image frame is a single geotagged image captured as part of a street view sequence. Each frame represents a specific point along the sequence route, typically taken at regular intervals (e.g., every few meters) as the camera moves through space.

Each image frame includes associated metadata such as:

  • Latitude and longitude – the GPS position where the image was taken
  • Heading – the direction the camera was facing
  • Timestamp – the exact time of capture
  • Sequence ID – a reference to the sequence it belongs to
  • Sequence index – its position/order within the sequence

In a map interface, individual photo frames can be visualized as markers or points along a polyline representing the full sequence. Users can click on a frame to view the corresponding street-level image or metadata.

These frames are the core building blocks of the street view experience, enabling step-by-step visual navigation along a path.

API Endpoint

GEThttps://api.openstreetcam.org/2.0/photo/?sequenceId=[sequenceId]&page=[page]&itemsPerPage=[itemsPerPage]

Example: https://api.openstreetcam.org/2.0/photo/?sequenceId=6187609&page=5&itemsPerPage=150

Request Parameters

ParameterTypeRequiredDescription
sequenceIdIntegerYesThe unique identifier of the sequence to retrieve photos from.
pageIntegerNoPage number for pagination (default: 1).
itemsPerPageIntegerNoNumber of items per page (default: 50, max: 150).

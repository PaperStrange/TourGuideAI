Companion to `iteration/recon/review-source-zh.md`. Every verdict in that file is bound to a
page listed here. Fetched 2026-09-30 (JST) with `curl` / `Invoke-WebRequest` (the harness
`web_fetch` tool is blocked in this environment). Browser UA + `Accept-Language: zh-CN`.

`SOURCES-plaintext.txt` is the concatenation of the `*.txt` renders of every file below
(regenerated by `extract-text.mjs`); `verify-quotes.mjs` checks the deliverable's `> ` quotes
against it. Note that several Chinese sites deliver the *visible* terms inside a client-side
template (`<script type="text/lizard-template">`, Next.js `pageProps` JSON), so a blanket
`<script>` strip deletes the clauses — hence the custom extractor. Do not substitute the
shared `html-to-text.mjs` when re-verifying.

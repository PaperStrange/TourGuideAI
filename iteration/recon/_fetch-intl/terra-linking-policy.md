# Linking Policy

The following Licensed Content shall at all times link back to the relevant Tripadvisor Site, where applicable:

* Photo content
* A “See all photos” link to Tripadvisor
* Property name linking to the Tripadvisor property page
* Property review count linking to Tripadvisor
* A “Read more…” link beneath truncated reviews linking to the full review on Tripadvisor
* A “More on Tripadvisor” link after the last review and for all AI review summaries for each property
* A “More on Tripadvisor” for all FAQ forum summaries
* A “Check Rates & Availability” link where the property, attraction, or restaurant is bookable on Tripadvisor
* A “Write a review” button enabling users to submit reviews on Tripadvisor

For Summaries (if applicable) include the following attribution:

* Include both (a) an-inline reference within the Summary to Tripadvisor that links to the applicable Tripadvisor Site and (b) a link to the applicable Tripadvisor Site as a source for the creation of the Summary.
* For property names, a link to the Tripadvisor property page
* For property review counts, a link to the applicable Tripadvisor property page
* For photo content, a link to the applicable linking to Tripadvisor property page
* A “See all photos” link to Tripadvisor
* A “Read more…” link beneath truncated reviews linking to the full review on Tripadvisor
* A “More on Tripadvisor” link after the last review and for all AI review summaries for each property

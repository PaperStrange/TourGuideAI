# L-C · 中文评价平台条款横评（目标玩家语言）

**本线只回答一个问题**：中文 UGC 平台的"附近兴趣点 + 用户评论"，能否被**永久存储**、并**随攻略离线打印再分发**？

**为什么这是唯一判据**：A4「附近兴趣点 + 5 条用户评论」已纳入范围（`iteration/design/design-core.md` §8.2.3）；攻略**必须可打印／可离线**（同文 §5：出门在外没有网）。
"能在网页上展示""能抓到""人气高"都不是判据——**能不能印在纸上让人带走**才是。原型路径（Google Places）已因 30 天缓存上限、§14.2 禁与非 Google 地图同用而不可用（`docs/handOff/evidence/CLAUSES-verbatim.md` §1）。

**方法**：本机 `web_fetch` 被拦；全部原文用 `curl` / `Invoke-WebRequest` 抓取（2026-09-30，JST）。
原始页面与纯文本渲染存于 `iteration/recon/_raw-review-zh/`（`SOURCES-plaintext.txt`）。

## 3. 明确回答：谁允许"离线打印再分发"？

**只有维基媒体系（维基导游中文版、中文维基百科），依据 CC BY-SA 4.0。其余全部中文平台没有任何一条允许。**

- 许可明文覆盖打印这一媒介：`许可人授权您在任何媒介以任何形式…行使本协议授予的权利`，且维基导游页把`打印`、`复印`、`出售`写进了用户可做的事。
- 署名在打印件上**做得到**：许可只要求"在合理可行情况下"给出网址(URI)/超链接，并允许"依据媒介、方法及情況…采用任何合理方式"满足署名；回链不是硬性前提。
- 商业可用：维基导游页自己写明作品`可能被用作商业、广告或者其他目的`，CC BY-SA 4.0 也无 NC 限制。
- **但有一条硬义务**：派生作品必须同许可——`您适用的"演绎作者的许可"协议必须是与本许可协议具有相同授权要素的知识共享许可协议`、`所有的作品和相应的衍生作品必须是相同的授权协议`。
  **后果**：任何**混入维基导游文字的成品攻略**，其相应部分必须以 CC BY-SA 4.0 分发，并附许可全文或链接；这意味着**别人也可以再分发这份攻略（含商业）**，我们无法禁止。这是产品级决策，不是文档细节。
- 反向结论同样明确：**知乎、哔哩哔哩、携程、穷游、大众点评/美团、去哪儿、飞猪、微信公众号、豆瓣，中文点评内容一律不可离线打印再分发。**
  它们的设计是"授权流向平台"（用户把永久/独家/可转授权给平台），再加"第三人使用须平台书面许可"或"须展示原链接"。**平台自己拿得到转授权，我们拿不到。**
- 因此本线**未发现任何中文 UGC 点评平台**可作为"5 条用户评论"的永久、可打印来源。若产品坚持"中文玩家读得懂的真实评论"，可行路径只剩：向平台取得书面／商务授权，或改用维基导游式的开放许可文本（其形态是**攻略条目，不是"5 条用户评论"**）。

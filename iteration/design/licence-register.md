## 2 · 这决定了什么（**这才是它值得登记的理由**）

### ✅ **PLATEAU 与 MLIT-KSJ 是 CC BY 4.0：署名即可，无审批**

| 来源 | 它解掉哪个开口 |
|---|---|
**PLATEAU 京都 2025** | **`GAP-HEIGHT-UNSOURCED` —— 163 栋楼无来源高度。** 而 `design-core.md` **9 处**把 PLATEAU 列为高度来源 |
**PLATEAU FAQ** | 数据实际从 **G空間情報センター** 下载——**获取路径**（许可证本身不解决"从哪拿"） |
**MLIT 位置参照情報** | **可能解 D-45**：若存在权威地址点数据集，**就不必从地址字符串推坐标**——而技能明确禁止后者：「*never derive a coordinate from an address string*」 |

### ⚠️ **GSI 走的是另一条路：可能需要国土地理院长的承認申請**

> **`測量法第29条（複製）` 与 `第30条（使用）`** —— **这不是"署名就好"的区别，是"要不要走一道审批"的区别。**

**而同一页也写着 `出典の明示だけで利用できる場合`**（只需明示出处即可使用的情形）——**所以答案取决于用途，而"取决"意味着这需要一个决定，不是一个默认值。**

**它挡着什么**：**`gsi-kiban.txt` 是场景几何底下的那张底图**（道路与建筑轮廓）。
**我的判断（供你裁决）**：**在高度层问题上先走 PLATEAU（CC BY 4.0，无审批），把 GSI 留作备选**——因为两者的用途部分重叠，而一条路要审批、另一条不要。

## 3 · 那个坏抓取：`odpt-developer.html` 不是条款页

**内容全文**：

```
開発者サイト You need to enable JavaScript to run this app.
```

**636 字节。它是一个 JavaScript 空壳，不含任何条款。**

**所以 ODPT 这条线的正确表述是**：

> **「我们抓取过一次，失败了；因此 ODPT 的开发者条款在本项目中【从未被读过】。」**

**而不是**：「我们持有 ODPT 条款快照。」

**按角色定义的不接受项**——「**一个从未被打开的 URL 不算验证**」——**这里必须记为"未取得"，不能算作已备证据。**

**我**没有**就地重抓**（那会毁掉失败的证据）。**正确 URL 应以 `.dsh/artifacts/` 为新落点重新抓取**，并保留这份失败记录。
